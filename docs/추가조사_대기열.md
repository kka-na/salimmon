1. **실구매 장기 후기 확충:** 2025-07-01~2026-10-21 사이 게시된 게시글 중 실제 6개월 이상 사용한 후기, 구매·A/S 실물 증빙 확인, 협찬 미제공 여부. 브랜드별 3개 이상의 독립 후기 목표. 협찬 여부가 `unknown`이면 '무보상 인증 완료'라고 표시 금지.
2. **모델 전시 확인:** 13개 매장에 정확한 모델명·경도·사이즈 전시 여부 전화 확인, 마지막 확인일과 전화번호, 해당 출처 기록.
3. **사진 저작권:** 제조사 공식 상품 이미지의 서비스 내 사용 허가/이미지 라이선스 확인. 사용 불가 시 공식 상품 상세페이지 링크+도감 플레이스홀더 유지.
4. **모든 주요 브랜드 3개 모델 채우기:** 킹코일, 현대리바트, 엘라비아, 소노시즌, 슬로우베드, 팔로모, 삼익가구, 까사미아 및 브랜드리스의 공식 모델명과 상세 규격/옵션 확보.
5. **A/S 표준화:** 정확한 스프링/폼/원단/프레임 부위별 보증, 정상적 경도변화 예외, 눌림 허용치, 교환 배송비, 방문비, 유통채널 구분.
6. **가격 정규화:** 같은 Q(또는 명확한 mm 규격) 모델의 정가/할인/프레임 견적을 별도로 수집. 구매자 견적을 판매가로 사용 금지.
7. **좌표 확보:** 공식 지도 또는 검증된 지도 데이터에서 매장 lat/lng 확인. 현재 주소는 지도 검색으로만 이용.
