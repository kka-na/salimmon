# 살림몬 침대 이미지 출처 v3

이 패키지는 침대 조사 v2(기존 59개 모델)의 **공식 상품 상세 URL 보강 데이터**입니다. v2 정보도 포함되어 있습니다.

- `research/`: 앱에 병합할 Markdown 원본 (스키마 v1, 59개 모델, 기타 파일 보존)
- `images/`: 59개 모델별 공식 상세 페이지 매핑 CSV·JSON 및 이미지 권리 안내 (사진 파일 자체 없음)
- `docs/research/`: v2 종합 보고서·조사 규격·후기 규칙·v3 이미지 매핑 보고서·잔여 조사 대기열

실제 브랜드 제품 이미지의 파일 저장·앱 내 재호스팅 권한은 확인되지 않아, 사진 파일을 임의로 다운로드하지 않았습니다. 정식 상세 페이지 OG 미리보기는 개발 앱의 `make previews`에서 처리합니다.
