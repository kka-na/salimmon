# 살림몬 침대 카테고리 조사 패키지

본 패키지는 앱 소스코드가 아니라 `조사MD_작성규격.md`의 `schema_version: 1`을 따르는 실사용 데이터입니다.

## 적용
- ZIP 내부 `research/` 디렉터리 전체를 기존 앱 저장소의 `research/`로 병합하십시오.
- `침대_종합_보고서.md`는 사람이 확인하기 위한 요약본입니다. 앱은 개별 entity 파일을 원본으로 사용합니다.
- 이미 같은 ID 파일이 있는 경우 내용을 비교한 후 갱신하십시오. 개인 도장/찜 기록이 들어있는 DB는 덮어쓰지 마십시오.

## v2 확장 사항
- 디시·더쿠·블라인드·Threads·인스타 등으로 실제 후기 **검색 범위** 확대. 플랫폼별 수집 정책은 `후기_검색범위_판정규칙.md`.
- 원문·작성일 확인된 신규 개인후기 **3건**(블라인드 2·더쿠 1) 등록. 총 11건이며 정확 날짜 확인 9건, 날짜 미확인 2건. 실제 무보상 구매 인증은 여전히 확인되지 않음.
- `검색커버리지_기록.md`에 검색 원문·기간 제외·접근 제한·다음 검색 작업 기록.
- 앱 엔티티 규격 `schema_version: 1` 유지(신규 review 필드만 optional).

## 품질 정책
- `verified`를 남발하지 않고 대부분 `partially_verified`/`researching`으로 표시합니다.
- `store_ids`는 취급 브랜드의 매장 **연관**이며, 해당 특정 모델 전시 보장이 아닙니다. 확정된 전시 제품은 `model_ids_on_display`에만 넣습니다(현재 전부 공란).
- 사용 허가를 확인하지 못한 상업용 제품 이미지 `image_url: null`. 상세 보고서의 공식 제품 페이지에서 원본 사진을 확인할 수 있습니다.
- 가격의 `size_or_option`이 '공식 시작가'면 결코 Q로 표시해서는 안 됩니다. `historical_official`은 현행 확정 판매가가 아닙니다.
- `sponsorship_status: unknown`은 무보상 확인을 뜻하지 않습니다. 엄격한 의미의 '내돈내산 확정'은 별도 영수증·협찬 부재 확인이 필요합니다.
- 게시일이 null인 해외 후기 2건은 기간 필터에 포함하지 마십시오.

## 추가 파일
- `추가조사_대기열.md`: 미확인 모델, 이미지, 가격, 후기, 매장 전화 검증 목록
- `DATA_QUALITY.json`: 엔티티 수·전시 확인 건수·후기 집계 품질 지표

- `후기_검색범위_판정규칙.md`: 앞으로 모든 혼수 카테고리에 적용되는 후기 검색·검증 기준
- `검색커버리지_기록.md`: 이번 확대 검색에서 무엇을 확인했는지/못했는지
