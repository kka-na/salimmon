## 0. 자료를 읽는 방법

이 보고서는 **사람이 확인하기 위한 종합판**입니다. 앱이 실제로 읽어야 할 구조화 데이터는 `research/{categories,brands,models,stores,reviews}/*.md` 파일들에 있습니다. 각 파일 앞의 YAML에 가격과 매장·후기 연결이 들어 있습니다.

검증 수준은 `partially_verified`(공식 또는 실구매 근거 일부 확인), `researching`(모델 최신성·가격 검증 부족)을 사용합니다. `verified`라고 확정한 모델은 아직 없습니다. 이는 누락을 숨기지 않기 위한 선택입니다.

가격 분류는 `official_list` 정가, `official_sale` 제조사 노출 할인가, `user_reported_paid` 개인 실결제 진술, `historical_official` 과거 기획전가입니다. **시작가는 Q 가격이 아닙니다.** 현재 노출된 공식 기획전 가격도 결제 단계의 최종 가격을 보장하지 않습니다.

제품 이미지는 사용 허가 여부가 검증되지 않아 `image.image_url: null`로 유지했습니다. 공식 상품 페이지는 `image_source_url`에서 확인할 수 있으며 앱에서는 이미지 플레이스홀더를 표시해야 합니다.

## 자주 비교되는 경도·구조
- **독립 포켓스프링:** 움직임 전달, 엣지 지지, 상면 쿠션을 직접 비교. 시몬스·무인양품·이케아·일룸 등.
- **하이브리드 Z 스프링:** 에이스의 로얄에이스 90H와 90S는 공식 규격 1500×2000(LQ), 1670×2075(K), 두께 400mm.
- **점탄성 폼:** 템퍼 폼/프리마/프로. 밀착감·이동 시 느낌과 열감을 충분히 체험.
- **서로 다른 경도 명칭:** 한 브랜드의 '미디엄'과 타 브랜드의 '미디엄'은 국제 통일 기준이 아님.

## 가격별 실제 비교 기준
- **100만원 안팎:** 이케아(150×200), 지누스 최저옵션, 무인양품 공식 기획전(현행 결제가 재확인).
- **200만~400만원 전후:** 씰리 베루스 Q 공식 할인, 일룸 헤이븐 Q, 한샘 현장 견적, 금성/에몬스 모델별 Q.
- **상위 등급:** 시몬스 자스민, 에이스 로얄에이스, 템퍼 프로, 에페다 상위, 베스트슬립 Z11.
- **가격 비교 주의:** 고객이 받은 혼수 견적에는 프레임·협탁·사은품이 섞이므로 매트리스 단품 가격 분리.

## 후기 신뢰도
- 실사용 개인글과 구매계약 글을 분리합니다. **구매만 한 글은 내구성 판단 근거가 아님.**
- 한샘 포시즌6 헤나 2025.08 후기의 경도 체감은 구형 '헤나'에 대한 것이며 현행 신형 6 모델에 직접 귀속하지 않았습니다.

- 플랫폼 후기·판매자 블로그는 협찬 여부가 불분명해 기본 집계 제외.

- 더쿠의 제품 없는 질문이나 모델명 없는 토퍼 체험은 브랜드별 모델의 장단점 근거로 쓰지 않음.
- 모든 후기의 구매·보상 여부는 실제 영수증 검증 전까지 `sponsorship_status: unknown` 유지.

## 6. 쇼룸 도장깨기 기록을 위한 비교 항목

각 제품을 실물 확인할 때 경도(1~10), 옆잠 어깨 압박, 허리 받침, 둘이 누웠을 때 흔들림, 엣지 지지, 프레임+매트리스 전체 높이, 현장 최종 Q/K 견적, 교환/반품비, 설치/수거비를 동일 기준으로 기록하는 것이 좋습니다.

```yaml
# 앱의 사용자 데이터베이스에서 별도로 관리할 방문 기록 예시
store_id: ikea-giheung
model_id: ikea-vesteroey-150
visit_status: tried        # wishlist | visited | tried | shortlisted | purchased
comfort_score: null        # 사용자 주관값, 연구 파일의 공식 평점이 아님
personal_note: null
visited_at: null
```

## v3 부록: 제품별 이미지·공식 상세페이지 출처 (2026-10-21)

기존 59개 제품 중 **신규 37개 모델**에 제품별 1:1 공식 상세 페이지 URL을 확인해 `research/models/`의 `image.image_source_url`을 업데이트했습니다. v2에 전용 URL이 있던 10개는 유지했으며, 나머지 12개는 전용 상세 페이지 미확인으로 변경하지 않았습니다.

사진 파일 저장·재배포 허가는 확인되지 않았습니다. 따라서 `images/`에 실제 JPG/PNG 파일을 넣지 않고 모델별 공식 출처 링크를 정리했습니다. 웹에서는 개발 에이전트가 구현한 링크형 OG 대표 이미지 미리보기(별도 활성화 필요)를 사용할 수 있습니다. 일룸 헤이븐 디럭스/시그니처와 N32 스프링 하드의 `og:image` 로고 문제는 미해결입니다.

- 전체 모델별 공식 출처: `images/model_image_mapping.csv`, `images/model_image_mapping.json`
- 이미지 상세 검증 및 잔여 12개 목록: `docs/research/침대_이미지_매핑_보고서_v3.md`
- 후속 조사: `docs/research/추가조사_대기열.md`

기존 가격·사양·후기·A/S·매장 데이터의 검증 수준은 v2와 동일하며, 이미지 출처 보강만으로 해당 정보의 정확성이 새로 검증된 것은 아닙니다.
