# 개발 에이전트 요청: 공식 상세 페이지 내부 사진 자동 추출

## 목적
N32·시몬스는 이미지가 JavaScript 렌더링 이후 나타나는 경우가 있습니다. 무인양품·에몬스는 상세 페이지 OG 이미지가 실제 제품 사진이 아니라 로고이거나 차단될 수 있습니다.

## 반드시 지킬 사항
- 정확한 모델 페이지를 브라우저에서 열고 `img.currentSrc`, `img.src`, `img.srcset`, `[data-src]`, 메타 태그를 수집한다.
- 이미지 후보의 실제 가시적 크기, 같은 모델명, 페이지 전용성, 로고/배너 여부를 평가한다. 중복 및 썸네일 제거.
- 다운로드·재호스팅을 하지 말고 먼저 후보 URL과 근거를 기록한다.
- `image_url`과 `rights_status: permitted/official_embed`는 별도 서면/약관 허락 없이는 채우지 않는다.
- 페이지별 후보를 모델 ID와 1:1 매칭하고, 각 이미지 파일 링크의 HTTP 응답, 이미지 규격, 화면에서 보이는 제품을 수동 검수한다.
- 제조사 사이트 내 이미지라 하더라도 링크 사용 조건은 별도 확인한다.

## 우선 모델
- 시몬스 `simmons-citrus`, `simmons-jasmine`, `simmons-tangerine`, `simmons-rutian-frame`.
- N32 `n32-foam-soft`, `n32-spring-hard`, `n32-spring-regular`. 레귤러 폼과 레귤러 스프링을 혼동하지 말 것.
- 공식 gallery 후보가 준비된 무인양품 6개, 에몬스 3개는 `images/공식_사진_원본후보_v4.csv` 확인.

브라우저에서만 나타나는 사진의 출처를 확인하더라도 `image_source_url`에는 모델별 **공식 상세 페이지**만 허용합니다. 공유 목록이나 이미지 파일 URL로 대체하지 않습니다.
