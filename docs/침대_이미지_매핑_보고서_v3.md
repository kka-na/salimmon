## 이미지 다운로드·사용권

브랜드 공식몰에서 이미지를 조회할 수 있다고 해서 제3자 앱에서 다운로드/재호스팅할 권한이 자동으로 생기지는 않습니다. 공식 이미지의 사용을 명시적으로 허용하는 근거(서면 허가, 미디어킷 사용조건 또는 라이선스)를 확보하지 못한 상태라 실제 JPG/PNG/WebP 복제본은 포함하지 않았습니다.

`images/`에는 매핑 CSV/JSON을 포함했습니다. 앱 개발자가 `make previews`를 실행하면 정식 상품 페이지의 OG 대표 이미지로 **링크형 미리보기**를 구성할 수 있습니다(실제 품질 검증 필요). 사용 허가가 확인된 때만 이미지 파일을 추가하고 `rights_status: permitted|official_embed` 및 근거 URL을 기재해야 합니다.

## 남은 확인 항목

1. 로고로 반환되는 일룸 헤이븐 디럭스·시그니처 Q, N32 스프링 하드 제품 이미지의 법적 사용 허용 여부
2. 베스트슬립 Z11, Z10B, G5 / 브랜드리스 모피어스22의 유효한 공식 전용 상세 페이지
3. 시몬스 헨리 / N32 스프링 레귤러 전용 상세 페이지
4. 에페다 3종의 현행 전용 상세 페이지(기존 404)
5. 퀵슬립 Q3/Q4/Q7 중 롤팩/일체형 세부 모델 구분 및 전용 상세 페이지
6. `make previews`를 통한 대표 사진·로고·중복 여부 실검증

## 개발 프로젝트 반영

1. 이 ZIP의 `research/`를 프로젝트 최상위 `research/`에 덮어쓰기 병합합니다(사용자 도장 기록이 있는 SQLite 파일은 건드리지 않음).
2. `images/`는 조사 출처 관리 폴더이며, 앱 이미지 파일 저장 폴더와는 별도입니다.
3. `make validate` 실행 후 `make previews` 실행, `OFFICIAL_IMAGE_PREVIEW=true`로 앱에서 확인합니다.
4. 신규 이미지 URL은 모두 외부 링크이며, 크롤러가 접근 제한을 받거나 OG 이미지가 로고일 경우 플레이스홀더로 유지합니다.
