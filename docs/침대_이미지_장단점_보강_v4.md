조사일: 2026-10-21. 기존 research/ 59개 모델 ID와 schema_version: 1 보존.

## 요약
- **모델별 사진 원본 URL 후보: 13개 확보**. 이 중 일부는 서버가 타임아웃·octet-stream 응답을 주어 이미지의 최종 HTTP 응답을 보장하지 않음.
- **개별 공식 상세 페이지 3개 보강**: 퀵슬립 뉴 Q3(19), Q4 롤팩(26), Q7 하이브리드(25). 국가별 접속 차단 가능성 존재.
- **프로·콘 구체화 24개 모델**, 나머지 35개 모델의 근거 없는 복붙 문장은 YAML에서 제거했음. 해당 모델의 심층 장단점은 별도 추가 조사 필요.
- 사진 JPG/PNG를 로컬 `images/`에 복제하지 않음. 공식 상품 사진이라도 외부 서비스에 저장·재배포할 명시적 권한이 없기 때문이며, `image.image_url: null`과 `rights_status: unknown` 유지.
- 앞선 이미지 미리보기 기능은 이미 존재하며, 3개의 새 제품 전용 URL과 v3에서 확인된 URL로 `make previews`를 재실행해야 함.

## 원본 사진 링크 매핑 규칙
- `images/공식_사진_원본후보_v4.csv`에 공식 상품 내부 이미지를 모델 ID별로 1:1 연결.
- `official_inline_image_url`은 확인 후보 **참조용**이고 앱의 `image.image_url` 스키마 필드에 복사해도 된다는 뜻이 아님.
- `official_product_gallery_verified`, `official_inline_photo_verified`: 외부 링크에서 해당 이미지가 화면에 표시되는 것까지 확인.
- `official_gallery_link_returned_timeout`, `official_gallery_image_unconfirmed_response`, `official_gallery_image_octet_stream`: 해당 링크는 발견했지만 서버 반환을 검증하지 못함.
- `official_marketing_visual_verified_not_dedicated_page`: 브랜드가 제품별로 구분해 제공한 사진이나 페이지는 여러 모델 공통이므로 앱 상세 URL에 사용하면 안 됨.

## 개발 에이전트 협업
1. `research/` 병합 후 `make validate` 실행.
2. `make previews`를 실행하고 새 URL의 실제 OG·제품 사진 출력 테스트.
3. 공식 제품 전용 이미지 후보의 표시 범위가 필요하다면, 우선 법무·브랜드 사용 정책 확인 후 `official_embed` 적용 가능성 검토. **임의로 `permitted`나 `official_embed`로 바꾸지 말 것.**
4. 브라우저 실행이 필요한 페이지는 `docs/research/개발_브라우저_사진_탐색_요청.md`를 따름.
5. 기존 `research/` 전체 교체 대신 병합하고 DB에 저장된 구매/방문/견적 기록 보존.
