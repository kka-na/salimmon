# 살림몬 혼수 도감 · 독립 후기 조사 소스 및 판정 규칙 v2

> 적용일: 2026-10-21 · 전 카테고리(침대, 소파, 식탁, 냉장고, 세탁기 등) 공통 · 기본 목표 기간: 2025-07-01~2026-10-21.

## 1. 조사 순서와 출처 분리

1. **제조사 공식 사이트·공식 매뉴얼:** 모델명, 규격, 경도, 판매가격, 보증/A/S, 판매 채널을 먼저 확인한다. 소비자 만족도 근거로는 사용하지 않는다.
2. **독립 구매·사용 후기:** 아래 모든 커뮤니티와 SNS에서 브랜드+모델명 조합으로 긍정·부정·A/S·장기 사용 후기를 각각 검색한다.
3. **가격 비교·실제 방문지:** 공식/공인 매장 위치와 전시 여부를 별도로 확인. 온라인 최저가와 소비자 실결제가도 별도 저장한다.
4. **교차검증:** 광고성, 동일인 복제 게시물, 모델 리뉴얼, 구매 전 체험과 장기 사용을 구별한다.

사이트별 편향을 피하려고 **브랜드별로 모든 필수 플랫폼을 검색**한다. 해당 플랫폼에 검색 결과가 없으면 `없음/접근 제한/미확인`을 구분하여 기록한다. 검색이 막혔을 때 결과가 없다고 단정하지 않는다. 링크를 확인할 수 없는 SNS 게시물은 정식 후기 개수에 넣지 않는다.

## 4. 인정·제외 등급

- **A. 구매 증빙 확인:** 공개 원문에 개인 정보 가린 영수증·주문내역·설치사진 등의 구매 근거가 실제 존재함. 이로써 무보상/협찬 부재가 자동으로 입증되지는 않는다.
- **B. 장기 실사용 주장:** 정확한 제품명과 구체적인 사용 기간(우선 6개월 이상), 실제 경험·단점이 있음.
- **C. 단기 실사용 주장:** 직접 사용은 했으나 6개월 미만 또는 사용 기간 미상.
- **D. 구매만/배송 대기:** 가격·구매 경로 참고용. 내구성·허리 편안함의 실사용 집계에서 제외.
- **E. 질문·매장 체험·지인 경험·브랜드 비교:** '탐색 참고'만 가능. 구매/사용 후기 개수에 넣지 않음.
- **X. 협찬/제공/원고료/할인조건/체험단/유료파트너십:** 독립 내돈내산 집계에서 제외. 상품평 작성 사은품·포인트 유도도 `incentivized`로 표시하여 독립 리뷰와 분리.

`purchase_evidence_level`과 `sponsorship_status`는 서로 독립적이다. **광고 표시가 없다는 이유만으로 `confirmed_uncompensated`로 올리지 않는다.** 공정위 표시 대상 협찬, 브랜드 인스타 계정 재게시, 제휴 링크, 프로필 협찬 이력, 동일 문구 다중 게재를 점검한다.

## 5. 중복과 정확성

- 동일 작성자의 블로그·Threads·인스타 동시 게시물은 원문을 여러 개 발견해도 **한 건**으로 중복 제거한다.
- 날짜는 링크 페이지에 확인된 **절대일만** `posted_at`에 넣는다. 검색 결과의 `3일 전`, 댓글 일자, 다른 페이지의 최신 날짜를 본문 작성일로 대체하지 않는다.
- 2025~2026년 작성된 '3~5년 사용'은 **게시일은 2025~2026**, 구매 시점은 이전이라는 점을 명시한다.
- 제품명·사이즈가 불명확하면 `model_id: null`로 저장한다. 구형·리뉴얼 제품을 현재 모델과 결합하지 않는다.
- 게시글의 과도한 단정(예: 특정 브랜드만 허리에 좋음)은 **작성자의 체감**으로만 기록한다. 의학적 사실이나 결함률 통계로 전환하지 않는다.
- SNS 공개 글만 이용하며 비공개 계정 접근 우회·스크랩 자동화·장문의 원문 복제를 하지 않는다. 짧게 요약하고 원문 링크를 남긴다.

## 6. review frontmatter 추가 필드(하위 호환)

현재 `schema_version: 1`을 유지하되 새 후기에는 다음 **선택적 필드**를 추가한다. 기존 앱 파서는 알 수 없는 필드를 무시할 수 있어야 한다.

```yaml
platform: theqoo         # dcinside | theqoo | blind | threads | instagram | naver_cafe | ...
content_access: full     # full | snippet_only | inaccessible
review_scope: mattress   # mattress | frame | topper | mixed
review_evidence_grade: B # A | B | C | D | E | X
in_period: true          # 기간·절대 게시일 확인 후에만 true
incentive_check: unknown # no_disclosure_found | disclosed | unknown (≠ 무보상 인증)
duplicate_group: null
```

### 앱 노출 규칙

- 장단점 카드에는 B/C(사용 후 경험)만 우선 노출하고, A는 구매 증빙 배지로 **별개 표시**.
- D는 '구매가·구매결정 참고' 탭, E는 '커뮤니티 의견' 탭으로 분리.
- X·게시일 미확인·원문 미열람 `snippet_only`는 독립 리뷰 통계에서 제외.
- 원문 링크·날짜·플랫폼·모델명·사용 기간·불확실성을 모든 후기 카드에 표시.

## 7. 브랜드별 검색 체크표

모델 3종마다 각 사이트 `검색완료/관련 후기 없음/접근 제한/추가확인` 상태를 기록한다. 모든 후기 링크와 검색 누락을 `검색커버리지_기록.md`에 보존한다. 아직 검색하지 않은 플랫폼을 '관련 후기 없음'이라고 표시하지 않는다.
