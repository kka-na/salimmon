# ⚠️ 테스트용 샘플 데이터 (실제 제품 정보 아님)

이 디렉터리의 모든 브랜드·모델·매장·후기·가격·좌표·URL은 **화면과 파이프라인 동작 확인을 위해 만든 가상 데이터**입니다.

- 모든 파일에 `is_sample: true`가 있고 이름 앞에 `[테스트]`가 붙어 있습니다.
- URL은 예약 도메인 `example.com`, 주소는 가상 주소입니다. 좌표는 지도 표시 시험용 임의 값입니다.
- 실제 구매 판단에 사용하지 마세요. 실제 조사 자료는 저장소 루트의 `research/`에 둡니다.

사용: `RESEARCH_DIR=samples/research` 로 서버를 실행합니다.
